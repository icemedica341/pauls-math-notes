# ARCHITECTURE

Quartz single page site. Config is `quartz.config.yaml` (YAML mode, no `quartz.config.ts` or `quartz.layout.ts`). Layout is a toolbar group plus page title and stock TableOfContents on the left. No Explorer component is enabled.

## Custom modules

| File                                            | Owns                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `quartz/components/scripts/toc.inline.ts`       | Entry only. Imports the three modules below, boots on load and on SPA `nav`, resets collapse and dwell state per page.                                                                                                                                                                                                                                                                                                                                                                                                            |
| `quartz/components/scripts/toc-collapse.ts`     | Entries, parents, chevron fold buttons, Collapse all / Expand all toolbar, label normalization. Starts expanded. Memory only, no localStorage or sessionStorage. No sort toggle.                                                                                                                                                                                                                                                                                                                                                  |
| `quartz/components/scripts/toc-dwell.ts`        | 450ms dwell overlay for truncated entries only (`scrollWidth > clientWidth`). Fixed position overlay, single line, normal weight, zero layout shift. Mouseleave, scroll, and Escape dismiss.                                                                                                                                                                                                                                                                                                                                      |
| `quartz/components/scripts/toc-scrollspy.ts`    | Single active entry scrollspy, pane centering from current position, click flight lock with settle and max timers, ancestor auto expand. Page scroll is never moved or stored.                                                                                                                                                                                                                                                                                                                                                    |
| `quartz/components/scripts/popover.inline.ts`   | Stock floating-ui popover for `a.internal` plus `scopeToSection`: prunes the cached clone to the target heading section (heading plus siblings up to the next same or higher level heading, `hr` never terminates, non heading anchors fall back to scroll).                                                                                                                                                                                                                                                                      |
| `quartz/styles/custom.scss`                     | Site override in 15 numbered sections. Paper background, 800px article width, KaTeX 1.2em, bold links with internal pill reset, content sized tables, 90 percent base scale, single page 2 column grid with right rail hidden and mobile stack restored, `.center` 900px cap with `min-width: 0` fix, TOC explorer theme, dwell overlay, chevron collapse animation, 0.8rem depth indents with theme adaptive guides, toolbar, quiet note callout, static TOC header label, deep heading sizes (h4 1.15rem, h5 1.05rem, h6 1rem). |
| `quartz/plugins/emitters/componentResources.ts` | Bundling. Stock TOC `afterDOMLoaded` (base scrollspy, overflow observer, header toggle) is suppressed by substring match so the custom script owns the pane. Custom `tocScript` is pushed unconditionally. Popover script and CSS are gated on `enablePopovers`.                                                                                                                                                                                                                                                                  |

Suppressed stock TOC: the producer (transformer to `fileData.toc`) and the emitted `div.toc` list stay. Only the stock behavior scripts are dropped. This removes 2 script bundles, which is why the build emits 51 files instead of 53.

900px cap intent: `.center` sets `max-width: 900px`, but base sets `.page > #quartz-body .center { min-width: 100% }` and min width wins over max width. The scoped `min-width: 0` override restores the cap.

## Data flow

1. `content/index.md` headings go through the TableOfContents transformer (maxDepth 4) into `fileData.toc`.
2. Stock TableOfContents component emits `div.toc > ul.toc-content.overflow > li.depth-N > a[href=#slug][data-for]` into the left sidebar via `DefaultFrame`, ordered by YAML priorities.
3. Browser: `toc.inline.ts` boot mutates the list (folds, toolbar, labels) and drives active class plus pane scroll. `custom.scss` styles it. Internal links go through `popover.inline.ts` to a floating-ui overlay. Clicks go through SPA micromorph plus `nav` event, then TOC and popover re init. CSS flows via `componentResources.ts` into `index-hash.css` linked by `Head.tsx`.

- Playwright F1 to F8 in `TOC-FEATURES.md`: structure, dwell, chevron, guides, pane scroll, scrollspy, toolbar, build. Verified at 1280px and 1920px.
